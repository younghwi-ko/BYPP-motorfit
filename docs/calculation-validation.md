# 계산 검산 및 버전 관리

이 문서는 MotorFit 계산 결과를 동일하게 재현하고, 기준값 변경을 추적하기 위한 운영 규칙입니다.

## 버전의 의미

- **계산 엔진 버전**: 후보 생성·정밀 계산·판정 순서를 구현한 코드 계약입니다. 계산식, 반올림, 정렬 기준 또는 판정 우선순위가 바뀌면 버전을 올립니다.
- **SRM/Excel 기준 버전**: 기존 SRM Excel 기준값과 golden fixture의 출처입니다. Excel의 공식 기준값이나 검산 fixture를 승인된 변경으로 갱신할 때 올립니다.
- **GSRM 기준 버전**: GSRM 변환 및 Engineering Check에 사용되는 기준값 묶음입니다. 기준 직경·공차·판정 경계를 변경할 때 올립니다.
- **AN 카탈로그 버전**: 공급된 AS568A 오링 목록과 항목 수를 식별합니다. 규격을 추가·삭제·수정하면 올립니다.

단순한 문구·레이아웃·접근성 변경은 계산 엔진이나 데이터 버전을 올리지 않습니다. 반대로 계산 결과에 영향을 주는 변경은 UI 변경으로 분류하지 않습니다.

## 기준값 변경 절차

1. 공통 `VALIDATION_FIXTURES`의 기존 fixture를 먼저 실행합니다.
2. 독립 검산 결과에서 숫자·상태·대표 후보·집계를 비교합니다.
3. 차이가 있으면 임의로 기대값을 바꾸지 말고 원인(공식, 데이터, 정렬, 입력)을 분석합니다.
4. 변경이 의도되고 승인된 경우에만 관련 버전과 golden fixture를 함께 갱신합니다.
5. 전체 단위 테스트, E2E, 성능 테스트와 CSV/JSON 메타데이터 검증을 다시 실행합니다.

계산식 변경은 반드시 기존 엔진과 분리된 검산 절차를 통과하고 승인된 뒤 반영합니다. 검산을 실행하지 않은 결과는 `검산하지 않음`으로 기록하며 PASS로 표시하지 않습니다.
