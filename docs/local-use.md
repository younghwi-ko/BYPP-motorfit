# MotorFit 로컬 사용 안내

MotorFit은 SRM 계산 결과를 교육·설계 검토 목적으로 확인하는 브라우저 도구입니다. 실제 제작·점화 승인용 결과가 아니며, 최종 설계에는 별도의 안전 검토와 승인이 필요합니다.

## 준비

- Node.js 24 계열을 권장합니다. README 문서 점검 환경은 Node.js 24.19.0입니다.
- pnpm: `package.json`의 `packageManager`는 11.19.0을 지정합니다. 문서 점검 환경은 11.25.0입니다.
- 비공개 저장소에서 내려받는 경우 해당 저장소 접근 권한

프로젝트 루트에서 lockfile에 맞춰 의존성을 설치합니다.

```powershell
pnpm install --frozen-lockfile
```

## 개발 서버

```powershell
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## production 빌드와 실행

```powershell
pnpm build
pnpm start
```

production 서버도 기본적으로 `http://localhost:3000`에서 실행됩니다. 같은 포트의 개발 서버는 먼저 종료하세요. 사용 설명서는 `/guide`에서 확인할 수 있습니다. 기본 실행에 별도 API 키는 필요하지 않습니다.

## 결과 저장과 백업

계산 결과 이력은 서버로 전송되지 않고 현재 브라우저의 `localStorage`에 최대 20개까지 저장됩니다. 브라우저 데이터 삭제, 프로필 변경, 저장공간 정리로 이력이 사라질 수 있으므로 중요한 검토 결과는 정기적으로 `계산 결과 이력 → 전체 이력 JSON 백업`을 사용해 파일로 보관하세요.

백업 복원은 `계산 결과 이력 → 백업 JSON 불러오기`에서 수행합니다. 파일을 확인한 뒤 기존 이력에 추가하거나 전체 교체할 수 있으며, 전체 교체 전에는 확인을 요구합니다. MotorFit이 아닌 파일, 손상된 JSON, 지원하지 않는 schema version은 거부합니다. 백업에는 schema version과 앱·계산 엔진·SRM 기준·GSRM 기준·AN 카탈로그 버전이 포함됩니다. 버전이 다른 결과는 현재 계산을 덮어쓰지 않고 이력으로만 보관하며, 화면에 경고를 표시합니다.

외부 검증 데이터·민감도 시나리오·RPA 기록·앱 자체 점검은 각 영역의 백업 기능을 사용합니다. 계산 이력 백업 하나가 모든 별도 기록을 합친 통합 백업은 아닙니다.

## 데이터 손실 방지

중요 결과는 계산 직후 JSON으로 백업하고, 백업 파일을 별도 저장소에 보관하세요. 복원된 결과는 현재 입력이나 현재 계산을 자동으로 바꾸지 않습니다. 저장 목록에서 다시 불러와 상세 비교·CSV/JSON 재내보내기를 수행할 수 있습니다.

## 로컬 사용을 권장하는 이유

GitHub private 저장소와 로컬 실행을 사용하면 계산 결과와 백업 파일이 사용자의 브라우저와 지정한 파일 위치에만 남습니다. Vercel 배포가 없어도 계산, 후보 판정, GSRM/AN 검사, 결과 저장·비교·내보내기의 전체 기능을 사용할 수 있습니다.
