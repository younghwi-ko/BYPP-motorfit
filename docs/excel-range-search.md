# Excel 재현 모드의 범위 탐색

## 모드와 생성 규칙

- 제작 후보 모드: 기존 정수 mm·5 mm 간격과 자동 탐색 결과를 유지합니다.
- Excel 재현 모드: Do·do·Lo의 입력 최소·최대값을 보존하고, 각 최소값에 정수 0, 1, 2, … mm를 더해 최대값 이하의 값만 생성합니다. 제작 모드의 5 mm 제약과 자동 범위 확장을 적용하지 않습니다.
- `40.5~42.5`는 `40.5, 41.5, 42.5`, `40.5~42.2`는 `40.5, 41.5`입니다. 임의의 끝점을 추가하거나 소수 시작값을 반올림하지 않습니다.
- 최소=최대이면 해당 치수는 한 값입니다. 세그먼트 수는 두 모드 모두 입력한 양의 정수 범위를 1씩 증가시킵니다. 역전 범위는 입력 오류입니다.
- 전체 후보 수 추정과 동기·비동기 엔진은 동일한 생성 함수를 사용하며, Worker가 범위를 단일 조합으로 축소하지 않습니다.

## 정밀 계산 제한과 성능

Excel 모드는 기존 설정의 `maxCandidateCount`를 정밀 계산 상한으로 사용합니다. 현재 화면 기본 설정은 200개이고, 엔진 API에서 미지정한 경우 기존 기본 상한은 2,000개입니다. 단일 조합으로 바꾸는 고정 상한 1은 제거했습니다.

상한은 입력 범위나 전체 조합 수를 줄이지 않습니다. 전체 범위에서 기존 질량 상한·형상 검증을 적용하며, 정밀 계산 대상으로 선택된 조합 수와 계산 실패·검증 탈락 수를 구분합니다. 상한 적용 시 `truncated: true`와 경고를 기록합니다. 정밀 대상의 기존 선택 순서와 최종 후보 판정·정렬은 변경하지 않습니다.

화면은 입력 영역과 결과에 실제 상한을 표시하고, 결과에는 전체 후보 수·정밀 계산 수·제한 적용 여부를 표시합니다. 목록에 보이는 일부 행이 전체 결과를 뜻하지는 않습니다. 정밀 상한은 전체 범위 열거 비용·메모리까지 제한하지 않으므로 큰 범위는 시간이 걸릴 수 있으며, Worker 진행률·취소·동일 입력 재계산을 사용할 수 있습니다.

## 저장·내보내기와 출처

- 모드 전환 시 입력 범위를 유지하면서 적용 간격을 1/5 mm로 기록합니다. 모드·범위·간격이 달라지면 기존 결과는 `재계산 필요` 상태가 됩니다.
- 결과의 `metadata.input`과 `searchEnvelope`에 실제 적용 범위·간격·세그먼트 범위를 기록합니다. Excel CSV/JSON의 입력값도 완료 당시 metadata를 사용하므로 입력을 수정해도 과거 결과의 출처가 바뀌지 않습니다.
- 저장 이력·JSON 백업·복원·재내보내기는 해당 snapshot을 보존합니다. 인쇄용 리포트에도 실제 범위·간격과 정밀 상한·제한 여부를 표시합니다.
- 범위 생성 계약 변경을 구분하기 위해 엔진 버전은 `candidate-search-2`입니다. SRM/Excel·GSRM 기준 버전과 AN 카탈로그 버전은 그대로입니다. 이전 저장 결과를 자동으로 새 결과로 덮어쓰지 않습니다.
- 목표 추력 공란은 Worker에서도 그대로 유지하며, 목표 추력 기반 지표를 임의의 기본값으로 계산하지 않습니다.

## 회귀 검증

검증 코드는 [단위 테스트](../tests/excel-range.test.ts)와 [실제 Worker E2E](../e2e/excel-range.spec.ts)에 있습니다.

- 정수 `Do 40~42 / do 10~12 / Lo 78~80 / 세그먼트 1~2`: 예상 치수 목록 및 54조합 대조.
- 소수 시작·비정렬 최대값: 24조합, 상한 바로 아래 경계, 소수 원본 정밀도 보존.
- `45×15×80/2` 단일 Excel 기준 케이스의 기존 질량·압력 기준값 재현.
- 제한 적용 시 전체 조합·범위 보존, 비정수/역전 세그먼트 오류, 결정성, 진행률·취소 후 재계산.
- CSV/JSON 실제 다운로드, 저장·삭제·JSON 백업 복원·저장 결과 재내보내기, 인쇄용 DOM·`window.print()` 호출 stub 확인, 390px 입력·실행.

인쇄 테스트는 실제 PDF 파일 저장을 뜻하지 않습니다. 이 기능은 교육·설계 검토용이며, 전역 최적해·하드웨어 안전성·제작·점화 승인을 제공하지 않습니다.

E2E의 `FORCE_COLOR`/`NO_COLOR` 출력 색상 경고와 느린 파일 안내(기존 `motorfit.spec.ts` 9.2분)가 있었습니다. 이는 lint 경고나 계산 실패가 아닙니다. 일반 Chrome 수동 QA와 실제 PDF 파일 저장을 이번에 새로 수행한 것으로 기록하지 않습니다.
