## 경고·미검증과 해석 제한

- Playwright 실행 프로세스에서 `FORCE_COLOR` 설정으로 `NO_COLOR`가 무시된다는 Node 경고가 출력됐습니다. 출력 색상 설정 경고이며 앱 계산 오류나 lint 경고가 아닙니다.
- Playwright는 `motorfit.spec.ts`(11.1분)를 느린 파일로 알리고 병렬 실행을 권장했습니다. 기존 `workers: 1` 설정을 그대로 사용했으며 테스트나 성능 기준을 완화하지 않았습니다.
- 이번 작업은 자동 테스트 실행입니다. 일반 Chrome에서의 별도 수동 QA, 실제 인쇄 대화상자 조작·PDF 파일 저장·종이 인쇄는 수행하지 않았습니다.
- 브라우저 콘솔 전체의 수동 전수 확인도 별도 수행하지 않았습니다. E2E 통과를 모든 콘솔 메시지가 없다는 증명으로 해석하지 않습니다.
- 자동 회귀·앱 자체 점검은 기준 모델 재현과 소프트웨어 동작 확인입니다. 독립적인 물리 검산 또는 실제 하드웨어 시험 검증이 아니며, 제작·점화 승인이나 안전 판정을 제공하지 않습니다.
- Vercel·공개 데모·저장소 공개 설정은 확인하거나 변경하지 않았습니다.
- 앱 코드·계산식·기준값·판정·기대값을 수정하지 않고 검증했습니다. 이번 작업의 변경 대상은 실행 결과 문서와 README 연결뿐입니다.
