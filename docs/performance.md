# MotorFit 브라우저 성능 측정

`pnpm test:performance`가 Playwright Chromium에서 대규모 후보 탐색을 실행한다. 측정 항목은 계산 시작 후 취소 UI 표시 여부, 취소 응답 시간, 취소 후 재계산 가능 여부, 최종 결과 표시 시간이다.

첫 15초 안에 취소 UI가 표시되어야 하며, 취소 응답 시간은 30초 미만이어야 한다. 취소 후 동일 입력을 다시 계산해 결과가 표시되는지도 검증한다. 이 기준은 계산 상한이나 후보 판정 기준을 변경하지 않고, 실제 브라우저에서 장시간 계산이 메인 스레드를 점유하지 않는지 확인한다.
