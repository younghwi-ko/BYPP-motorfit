# MotorFit 릴리스 체크리스트

릴리스 후보를 로컬 production 서버에서 확인하고, 결과를 `PASS`, `FAIL`, `확인 불가` 중 하나로 기록합니다. 계산 결과·기준값·판정 기준을 임의로 바꾸어 PASS로 만들지 않습니다.

| 항목 | 상태(PASS/FAIL/확인 불가) | 확인 시각 | 근거·메모 |
| --- | --- | --- | --- |
| 기준 예시 계산 |  |  | 0.3956 kg / 4.1 MPa |
| 2 kg 케이스 |  |  | 2.000 kg / 4.0 MPa / 추력 미입력 |
| 0.763 kg 참고 후보 |  |  | 55×20×105/2 재현 |
| 8개 자동 추천 회귀 |  |  | 전체 케이스 실행 |
| GSRM B=49 mm 기준 케이스 |  |  | AN-132-NBR 기준 |
| AN 241개 검사 |  |  | 판정 합계 241개 |
| 계산 취소·재계산 |  |  | CANCELLED 후 재계산 |
| 결과 저장·불러오기·삭제 |  |  | localStorage 이력 |
| 전체 백업·복원 |  |  | schema version 및 손상 파일 검사 |
| CSV/JSON 내보내기 |  |  | 입력·metadata·집계 일치 |
| 인쇄/PDF 설계 검토 리포트 |  |  | 현재/저장 결과 |
| 모델 적용 범위와 한계 |  |  | 하드웨어 검증·제작 승인 미제공 |
| 모바일 390px |  |  | 입력·결과·리포트 버튼 |
| 엔진·앱·SRM·GSRM·AN 버전 |  |  | 공통 metadata와 일치 |
| 작업 트리 clean |  |  | `git status --short` |
| `main` 동기화 |  |  | `git rev-parse HEAD`와 `origin/main` |

## 기록 원칙

- 기준 모델 재현과 계산 재현성은 실제 하드웨어 시험 검증과 구분합니다.
- 하드웨어 시험 데이터가 등록되지 않은 경우 `확인되지 않음`으로 기록합니다.
- 목표 추력 미입력, 근사 탐색, 전역 최적해 비보장 문구가 결과와 리포트에 남아 있는지 확인합니다.
- localStorage와 백업 파일에는 계산 결과와 metadata만 포함되며 비밀번호·API 키·환경변수를 포함하지 않아야 합니다.
- 브라우저 데이터 삭제 시 localStorage 이력이 사라질 수 있으므로 JSON 백업을 별도 보관합니다.
